How Downloads works

Sign in with the name and password you were given. Everything here is locked: the list of apps, the pictures and the files stay scrambled until you sign in, and they unlock only inside your own browser.

Pick a shelf: Pulse Labs PC (Windows programs), Pulse Labs Droid (phone and tablet apps) or Chrome Extensions. Tap it and it jumps open to every app on that shelf.

Every app card shows at a glance what it's for, which system it runs on, the newest version and when it was built, with Download and Share right on the card. Tap the card for the full page: bullet list, pictures of every screen, what changed, and the downloads. The red undo arrow takes you back one step.

Share makes a link for that one build only. Whoever gets it can download that file without signing in, and nothing else. When a newer build replaces it, the old link stops working. Anyone holding the link can use it, so send it only to the person it's for.

Test build means bench-signed for testing. It won't install over a store copy of the same app.

Phone apps download as an APK. Open it and allow the install. It installs over the old version, so settings stay. PC apps download as an exe or zip.

Every file has a fingerprint (SHA-256), and the page checks each download is untouched before handing it over.

Every build (on each app page) lists every version ever made, newest on top. Tap a date to read that build's changelog. The newest builds download right here. Older ones say "Archived" and link to the farm's copy on GitHub, so nothing is ever lost.

Report a problem (on each app page) sends a ticket: what happened, the pasted log and a screenshot. The farm picks it up within a couple of minutes. The ticket's status shows on the app page: New, Being fixed, Fixed in v…, or Needs Jason.

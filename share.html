About this link

This link opens one test build of a Pulse Labs app, and nothing else. The file is stored scrambled; the key to unscramble it is inside the link itself, after the # sign, and never gets sent to any server.

If the link says the build is gone, a newer version has replaced it. Ask for a fresh link.

Android: open the downloaded APK and allow the install. PC: run the exe or unzip the zip.

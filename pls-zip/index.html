PLS Zip

Windows PCAndroid (inside PLS Explorer)

Open any zip or archive, old or new. The old RAR from a backup drive, the 7z a friend sent, the file that came in five parts: PLS Zip opens them. It's our own engine, built from scratch, so it keeps opening the old formats other tools quietly drop.

Coming soon for Windows. On Android it already works today inside PLS Explorer.

Opens

zip (also password zips) · 7z · RAR, from old RAR 2.9 up to RAR 5 · tar · tar.gz · tar.bz2 · gz · bz2 · archives split into parts (.7z.001, .part1.rar, .r00) · locked 7z with hidden file names

Makes

Zip files, with or without a password. Passwords use AES-256, the same strong lock banks use.

Never touches your original

Extracting always makes a new folder next to the archive. Nothing is overwritten, nothing is deleted.

Offline, no strings

No internet, no ads, no account, no subscription. Opening archives is free forever.

Backwards compatible, on purpose

Plenty of tools have stopped opening older archives. PLS Zip reads the old RAR versions, every common 7z packing method (LZMA, LZMA2, PPMd, BZip2, Deflate) and archives split across many files. We test it against archives made by other programs, file by file, byte for byte.

Plain words when something's wrong

"The password is wrong." "This is part 2: open part 1." No codes, no guessing.
